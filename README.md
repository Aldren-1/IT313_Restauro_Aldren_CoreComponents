
# IT313 Laboratory 6 - Student Directory Viewer

## Problem Description

The Student Directory Viewer is a React Native application
that helps academic advisers browse and search students
who need academic advising.

Users can view student photos, names, and year levels.
They can also search for students and flag them for advising.

## Component Structure

### StudentCard

StudentCard displays individual student information,
including their photo, name, year level, and flag button.

### StudentDirectory

StudentDirectory manages the student list, search query,
and flagging functionality.

## React Native Components Used

- View
- Text
- Image
- ScrollView
- TextInput
- Pressable

## How to Run

1. Install dependencies:

   npm install

2. Start the Expo application:

   npx expo start

3. Scan the QR code using Expo Go.

## Technologies Used

- React Native
