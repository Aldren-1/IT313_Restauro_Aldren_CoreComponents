Laboratory 6 - IT 313 – Mobile Programming
Video Demonstration: React Native Core Components in Action
Objective
Demonstrate your understanding of React Native's core components by solving a programming problem that
requires you to lay out a screen with View, Text, and Image, build a scrollable and searchable list with ScrollView
and TextInput, and handle touch interaction with Pressable — and recording a video that shows and explains your
solution as you write, run, and test it.
The Problem: Student Directory Viewer
The IT313 registrar has given you a list of students who need academic advising this term. Your task is to build a
small Expo (React Native) screen that lets an adviser browse and search this list, in the style of a real studentdirectory app.
Starter data (place this in your screen component or a separate data file):
const students = [
 { id: "s1", name: "Ana Cruz", year: "3rd Year", photoUrl: "https://i.pravatar.cc/100?
img=1" },
 { id: "s2", name: "Bea Santos", year: "2nd Year", photoUrl: "https://i.pravatar.cc/100?
img=2" },
 { id: "s3", name: "Cid Ramos", year: "4th Year", photoUrl: "https://i.pravatar.cc/100?
img=3" },
 { id: "s4", name: "Dex Alonzo", year: "1st Year", photoUrl: "https://i.pravatar.cc/100?
img=4" },
 { id: "s5", name: "Eli Tan", year: "3rd Year", photoUrl: "https://i.pravatar.cc/100?
img=5" },
];
Expected screen: a search box at the top; below it, inside a scrollable list, one card per student showing their photo,
name, and year level; each card has a "Flag for Advising" control that visibly changes appearance when
pressed/toggled; typing in the search box narrows the visible cards to names that match.
High-level design (wireframe) for reference only. Your layout, colors, and styling may differ as long as every
requirement is met.
Requirements — your solution must:
1. Build a functional component named StudentCard that receives id, name, year, photoUrl, flagged, and
onToggleFlag as props, and lays them out with a View containing an Image and two Text elements.
2. Give the Image an explicit width/height and rounded corners via StyleSheet.create, and use Flexbox on the
surrounding View to align the photo and text side by side.
3. Build a parent component named StudentDirectory that holds the students array in state and renders one
StudentCard per student inside a ScrollView, using .map() with a stable key={student.id}.
4. Add a TextInput above the ScrollView bound to a query state via value and onChangeText, and use conditional
filtering so only students whose name includes the typed text (case-insensitive) are rendered.
5. Give each StudentCard a Pressable "Flag for Advising" control whose style function ({ pressed }) => ... and
whose color also reflects a flagged boolean in state, and wire onToggleFlag so pressing it updates that student's
flagged state in the parent.
6. Temporarily remove the value/onChangeText pair from the TextInput (make it uncontrolled) and observe what
happens to filtering as you type, then restore it.
7. Include a README.md in your project explaining the problem, your component structure (StudentCard vs.
StudentDirectory), and how to run the app (npx expo start).
